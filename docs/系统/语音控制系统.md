# 语音控制系统

## 概述

语音控制系统提供 **3x3 矩阵** 级别的精细控制，允许玩家独立开关 3 个游戏阶段下 3 种语音类型的播放。设置通过存档系统持久化到本地和云端。

### 控制矩阵

|              | 竞拍大厅 (lobby) | 竞拍回合 (auction) | 结算阶段 (settlement) |
|--------------|:---:|:---:|:---:|
| **玩家角色** | on/off | on/off | on/off |
| **AI 角色**  | on/off | on/off | on/off |
| **旁白**     | on/off | on/off | on/off |

默认仅开启**玩家角色**在**竞拍回合**和**结算阶段**的语音，其余全部关闭。

---

## 架构

系统采用三层分离设计：

```
GameController (调用方)
       |
       |  VoiceManager.PlayNarrator(key, phase)
       |  VoiceManager.PlayCharacterById(id, action, phase, isPlayer)
       v
AudioDirector (调度层 - 透明 Hook)
       |  拦截调用，添加排队/节流/去重
       |  透传 phase + isPlayer 到队列条目
       v
VoiceManager (播放引擎)
       |  查询 VoiceConfig 判断是否允许
       |  允许 -> SoundSource:Play()
       v
VoiceConfig (策略层 - 3x3 矩阵)
       |
       v
SaveSystem (持久化)
       存储到本地文件 + 云端 clientCloud
```

### 层次职责

| 层 | 文件 | 职责 |
|----|------|------|
| 策略层 | `scripts/UI/VoiceConfig.lua` | 持有 3x3 布尔矩阵，提供查询/设置/序列化接口 |
| 播放层 | `scripts/UI/VoiceManager.lua` | 资源预加载，播放前查 VoiceConfig，驱动 SoundSource |
| 调度层 | `scripts/UI/AudioDirector.lua` | 透明 Hook，语音排队/去重/节流，透传上下文 |
| UI 层 | `scripts/UI/SettingsPanel.lua` | 3x3 Toggle 矩阵界面 |
| 持久化 | `scripts/SaveSystem.lua` | 存储 voiceConfig 字段，旧格式自动迁移 |

## 模块详解

### 1. VoiceConfig (策略层)

**文件**: `scripts/UI/VoiceConfig.lua`

纯数据模块，不涉及音频播放。

#### 常量

```lua
-- 游戏阶段
VoiceConfig.PHASE_LOBBY      = "lobby"
VoiceConfig.PHASE_AUCTION    = "auction"
VoiceConfig.PHASE_SETTLEMENT = "settlement"

-- 语音类型
VoiceConfig.VOICE_PLAYER   = "player"
VoiceConfig.VOICE_AI       = "ai"
VoiceConfig.VOICE_NARRATOR = "narrator"
```

#### 内部数据结构

```lua
config = {
    lobby      = { player = false, ai = false, narrator = false },
    auction    = { player = true,  ai = false, narrator = false },
    settlement = { player = true,  ai = false, narrator = false },
}
```

#### 核心 API

| 方法 | 说明 |
|------|------|
| `IsEnabled(phase, voiceType)` | 查询指定开关状态，未知 phase/type 默认返回 true |
| `SetEnabled(phase, voiceType, enabled)` | 设置开关，触发 onChange 回调 |
| `GetAll()` | 返回深拷贝，用于序列化到 SaveSystem |
| `SetAll(data)` | 从持久化数据恢复，静默不触发回调 |
| `SetOnChange(callback)` | 注册变更回调（SettingsPanel 用于自动保存） |
| `ResetToDefaults()` | 重置所有开关为 true |

#### 便捷查询 (供 VoiceManager 调用)

| 方法 | 说明 |
|------|------|
| `IsNarratorEnabled(phase)` | 等价于 `IsEnabled(phase, "narrator")` |
| `IsCharacterEnabled(phase, isPlayer)` | isPlayer=true 查 "player"，false 查 "ai" |

#### 旧格式迁移

```lua
VoiceConfig.MigrateFromLegacy(narratorEnabled, characterEnabled)
```

将旧版的 2 个布尔开关（narratorEnabled / characterEnabled）展开为 3x3 矩阵，所有阶段统一应用相同值。

### 2. VoiceManager (播放引擎)

**文件**: `scripts/UI/VoiceManager.lua`

#### 初始化

`VoiceManager.Init()` 预加载所有语音 `.ogg` 文件到内存表 `voiceSounds`：

- **旁白**: `audio/voice/narrator_{eventKey}_1_旁白.ogg`
- **角色(旧格式)**: `audio/voice/char_{abbr}_{action}_1_{name}.ogg` (bid/forfeit/win/bluff)
- **角色(新格式)**: `audio/voice/{action}_{charId}_{name}.ogg` (regret/celebrate/greet/round_start/overbid)

创建单个 `SoundSource` 节点，新语音播放时打断旧语音。

#### 播放 API

```lua
VoiceManager.PlayNarrator(eventKey, phase)
VoiceManager.PlayCharacter(charName, action, phase, isPlayer)
VoiceManager.PlayCharacterById(charId, action, phase, isPlayer)
```

**参数说明**:

| 参数 | 类型 | 说明 |
|------|------|------|
| `phase` | string/nil | 游戏阶段常量。nil 时跳过配置检查（向后兼容） |
| `isPlayer` | boolean/nil | true=玩家角色, false=AI 角色。nil 按 AI 处理 |

**播放流程**:

```
收到调用 (key, phase, isPlayer)
    |
    v
phase 为 nil? --是--> 直接播放
    |否
    v
查询 VoiceConfig
    |
    v
启用? --否--> return (静默跳过)
    |是
    v
查找 voiceSounds[soundKey]
    |
    v
SoundSource:Play(sound)
```

#### 其他 API

| 方法 | 说明 |
|------|------|
| `Stop()` | 停止当前语音 |
| `IsPlaying()` | 查询是否正在播放 |

### 3. AudioDirector (调度层)

**文件**: `scripts/UI/AudioDirector.lua`

透明拦截层，在 `Init()` 时用闭包替换 VoiceManager 的公共方法，外部代码无需改动。

#### Hook 机制

```lua
-- Init() 时保存原始函数
origPlayNarrator = VoiceManager.PlayNarrator

-- 替换为 Hook 版本
VoiceManager.PlayNarrator = function(key, phase)
    scheduleVoice({ type = "narrator", key = key, phase = phase })
end
```

调用方（GameController）继续调用 `VoiceManager.PlayNarrator()`，实际执行的是 AudioDirector 的调度逻辑。

#### 调度规则

| 正在播放 | 新到达 | 行为 |
|---------|--------|------|
| 无 | 任何 | 直接播放 |
| 角色 | 角色 | 丢弃（让当前角色说完） |
| 角色 | 旁白 | 丢弃（角色不可打断） |
| 旁白 | 角色 | 排队（等旁白说完再播） |
| 旁白 | 旁白 | 排队 FIFO（最多等 2 秒，超时打断） |

#### 去重

- 正在播放相同语音 -> 跳过
- 队列中已有相同语音 -> 跳过
- 唯一标识格式: `"n:info_reveal"` / `"c:林远舟:bid"` / `"ci:3:win"`

#### 音效节流

对 `Utils.PlaySfx()` 同样进行 Hook，相同音效在冷却期内不重复播放：

```lua
sfxThrottle = {
    timer_tick = 0.85,  -- 0.85秒内不重复
    ui_click   = 0.1,
}
```

#### phase/isPlayer 透传

队列条目携带 `phase` 和 `isPlayer` 字段，在实际调用 `origPlayNarrator` / `origPlayCharacter` 时原样传回，确保 VoiceConfig 的检查在最终播放时执行。

#### API

| 方法 | 说明 |
|------|------|
| `Init()` | 安装 Hook、重置队列（每局开始时调用） |
| `Update(dt)` | 每帧驱动队列处理和延迟动作 |
| `Delay(seconds, callback)` | 延迟执行回调 |
| `CancelAll()` | 清空队列和延迟动作 |
| `GetSpeakingCharId()` | 获取当前正在说话的角色 ID |
| `SetSfxThrottle(name, seconds)` | 运行时调整音效冷却 |

### 4. SettingsPanel (UI 层)

**文件**: `scripts/UI/SettingsPanel.lua`

在设置弹窗中渲染 3x3 Toggle 矩阵：

```
     ┌─────────────────────────────────┐
     │  语音控制                        │
     │          大厅    回合    结算     │
     │  玩家角色 [●]    [●]    [●]     │
     │  AI角色   [●]    [●]    [●]     │
     │  旁白     [●]    [●]    [●]     │
     └─────────────────────────────────┘
```

- 使用 `UI.Toggle` 控件（iOS 风格开关）
- 每个 Toggle 的 `onChange` 调用 `VoiceConfig.SetEnabled(phase, vtype, val)`
- VoiceConfig 的 onChange 回调触发 `SaveSettings()` -> `SaveSystem.UpdateSettings()`

---

### 5. 持久化 (SaveSystem)

**文件**: `scripts/SaveSystem.lua`

#### 存储结构

`saveData.settings.voiceConfig` 字段存储 3x3 矩阵的序列化形式：

```json
{
  "settings": {
    "bgmVolume": 100,
    "sfxVolume": 100,
    "voiceConfig": {
      "lobby":      { "player": true, "ai": true, "narrator": true },
      "auction":    { "player": true, "ai": false, "narrator": true },
      "settlement": { "player": true, "ai": true, "narrator": false }
    }
  }
}
```

#### 保存流程

```
Toggle 切换
  -> VoiceConfig.SetEnabled()
  -> onChange -> SettingsPanel.SaveSettings()
  -> SaveSystem.UpdateSettings({ voiceConfig = VoiceConfig.GetAll() })
  -> MarkDirty() -> 延迟5秒合并写入
  -> saveLocal() + saveCloud()
```

#### 加载流程

```
SaveSystem.Init()
  -> loadCloud() 拉取云端数据
  -> mergeGroups() 解析 settings 组
     -> 检测 voiceConfig 字段: 有则直接使用
     -> 检测旧字段 narratorEnabled/characterEnabled: 调用 MigrateFromLegacy()
  -> SettingsPanel.ApplySettings()
  -> VoiceConfig.SetAll(data)
```

#### 旧格式迁移

两处自动迁移逻辑，覆盖所有加载路径：

| 加载路径 | 位置 | 迁移逻辑 |
|---------|------|---------|
| 云端加载 | `mergeGroups()` | 检测旧字段 -> `VoiceConfig.MigrateFromLegacy()` |
| 本地缓存 | `loadLocal()` | 检测旧字段 -> `VoiceConfig.MigrateFromLegacy()`，清除旧字段 |

## GameController 调用点一览

| 游戏事件 | 调用 | phase | isPlayer |
|---------|------|-------|----------|
| 开局 AI 打招呼 | `PlayCharacterById(id, "greet", ...)` | lobby | false |
| 回合开始 AI 台词 | `PlayCharacterById(id, "round_start", ...)` | auction | false |
| 信息揭示旁白 | `PlayNarrator("info_reveal", ...)` | auction | - |
| 出价揭示旁白 | `PlayNarrator("bid_reveal", ...)` | auction | - |
| AI 虚张声势/弃权 | `PlayCharacterById(id, "bluff"/"forfeit", ...)` | auction | false |
| 加赛旁白 | `PlayNarrator("tiebreak", ...)` | auction | - |
| 判定胜负旁白 | `PlayNarrator("judge_win"/"judge_fail", ...)` | auction | - |
| 获胜者台词 | `PlayCharacterById(id, "win", ...)` | auction | IsLocalPlayer() |
| 超额出价者台词 | `PlayCharacterById(id, "overbid", ...)` | auction | IsLocalPlayer() |
| 结算庆祝/后悔 | `PlayCharacterById(id, "celebrate"/"regret", ...)` | settlement | winnerIsLocal |

`IsLocalPlayer(playerIdx)` 辅助函数：单机模式下 slot 1 为玩家，联网模式下通过 `GS.GetMySlot()` 判断。

## 扩展指南

### 新增游戏阶段

1. 在 `VoiceConfig.lua` 添加常量和 `PHASES` 列表条目
2. 在 `config` 默认值和 `CreateDefaults()` 中添加该阶段
3. 在 `SettingsPanel.lua` 的 `PHASE_SHORT_LABELS` 中添加列标题
4. 在 `GameController.lua` 对应位置使用新阶段常量

### 新增语音类型

1. 在 `VoiceConfig.lua` 添加常量和 `VOICE_TYPES` 列表条目
2. 在 `config` 默认值每个阶段中添加该类型
3. 在 `VoiceConfig` 添加便捷查询方法
4. 在 `VoiceManager` 中添加对应的播放检查逻辑
5. 在 `SettingsPanel.lua` 的 `TYPE_LABELS` 中添加行标签
