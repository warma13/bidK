# 竞拍游戏经济系统分析报告

## 核心问题：玩家轻松赚到几亿金币

从截图看到玩家资产 8.6 亿，排行榜前7名全在 2-4.7 亿级别。说明当前经济系统严重失衡，玩家可以无风险大量套利。

---

## 致命漏洞分析

### 漏洞 #1：100% 回收价格（最致命）

**位置：** `RecycleManager.lua`

```lua
function RecycleManager.GetRecycleValue(item)
    return item.realValue or item.baseValue or 0
end
```

物品按**真实价值的 100%** 回收，完全没有折扣。现实中典当行 30-50%，拍卖行 50-70%，这里是 100%。这意味着只要出价低于物品总价值，**每一局都稳赚**。

---

### 漏洞 #2：AI 出价上限过低

**位置：** `AI/Strategies.lua` - `baseCompeteBid` 函数

| 参数 | 当前值 | 含义 |
|------|--------|------|
| floorRatio | 0.50 | AI 底价 = 期望价值 × 50% |
| absoluteFloor | expectedValue × 0.40 | 最低保护价 = 40% |
| positionLow/High | 0.3 ~ 0.7 | AI出价在底价和估值之间取中间位置 |

**结果：** AI 实际出价通常在期望价值的 **40%-70%** 之间。玩家只需出价略高于 AI，就能以远低于真实价值的价格拿下仓库。

---

### 漏洞 #3：高难度场次利润空间巨大

**位置：** `Config.lua` 各难度配置

| 难度 | 入场费 | 期望价值 | AI 典型出价(~45%) | 玩家出价 | 100%回收 | **单局利润** |
|------|--------|---------|-------------------|---------|---------|------------|
| 简单 | 0 | 3万 | 1.3万 | 1.5万 | 3万 | **1.5万** |
| 普通 | 5千 | 10万 | 4.5万 | 5万 | 10万 | **4.5万** |
| 困难 | 2.5万 | 50万 | 22万 | 25万 | 50万 | **22.5万** |
| 噩梦 | 4万 | 1000万 | 450万 | 500万 | 1000万 | **456万** |
| 专家 | 8万 | 1000万 | 450万 | 500万 | 1000万 | **492万** |
| **传奇** | **20万** | **5000万** | **2250万** | **2500万** | **5000万** | **2780万** |

**传奇场打10局 = 2.78亿利润**，这就是为什么排行榜全是几亿。

---

### 漏洞 #4：倍率机制让 AI 前期放弃

**位置：** `AI/Strategies.lua` - `shouldAllIn`

前几轮倍率高（×2.0, ×1.6），AI 梭哈概率只有 10-25%，很容易放弃。玩家可以在高倍率阶段用低价试探，无风险淘汰 AI。

---

### 漏洞 #5：入场费与回报严重不成比例

| 难度 | 入场费 | 期望回报 | 回报/入场费比 |
|------|--------|---------|-------------|
| 传奇 | 20万 | 5000万 | **250倍** |
| 噩梦 | 4万 | 1000万 | **250倍** |
| 专家 | 8万 | 1000万 | **125倍** |

入场费几乎可以忽略不计，没有任何风险控制作用。

---

## 缺失的经济调控机制

1. **无回收折扣** — 100% 回收 = 无损套利
2. **无交易税/手续费** — 回收无佣金、拍卖无税
3. **无失败惩罚** — 出价失败只损失入场费，而入场费微不足道
4. **无通胀控制** — 没有金币消耗渠道（仓库升级消耗很少）
5. **AI 不会学习** — 固定策略，被套路后无法适应
6. **无次数限制** — 高利润场次可无限刷

---

## 修复建议

### P0 — 立即修复（最大影响）

#### 1. 回收价格打折

```
回收率 = 60-70%（而非 100%）
```

这一条改动就能大幅压缩利润空间。以传奇场为例：
- 修复前利润：5000万 × 100% - 2500万 = 2500万
- 修复后利润：5000万 × 65% - 2500万 = 750万（降低 70%）

#### 2. AI 底价提升

```
floorRatio: 0.50 → 0.70
absoluteFloor: 0.40 → 0.60
```

AI 出价从 40-70% 提升到 60-85%，压缩玩家套利空间。

### P1 — 高优先级

#### 3. 大幅提高入场费

```
传奇入场费: 20万 → 300-500万
噩梦入场费: 4万 → 50-100万
```

让入场费成为真正的风险因子，不是走过场。

#### 4. 降低高难度期望价值（或调整价值分布）

```
传奇期望价值: 5000万 → 2000万
```

或者增加价值方差，让部分仓库"亏本"（真实价值低于出价），增加赌博感。

#### 5. 调整倍率曲线

```
当前: 2.0, 1.6, 1.4, 1.2, 1.01
建议: 1.4, 1.25, 1.15, 1.08, 1.01
```

前期倍率降低，AI 更敢出价，竞争更激烈。

### P2 — 中优先级

#### 6. 添加金币沉没渠道

- 仓库维护费（每日扣除）
- 物品修复/鉴定费
- 拍卖佣金（赢得拍卖额外收 5-10%）

#### 7. 动态难度调整

- 玩家连续赢利时，AI 出价更激进
- 玩家资产超过阈值时，解锁更贵的场次但 AI 也更强
- 根据玩家胜率调整 AI 策略参数

#### 8. 价值随机波动

- 仓库实际价值在期望价值的 70-130% 之间随机波动
- 有概率出现"空仓"（价值远低于预期），增加风险感

---

## 修复后的经济平衡目标

理想状态下的游戏经济：

| 指标 | 当前 | 目标 |
|------|------|------|
| 单局胜率 | ~90%（AI太弱） | 50-60% |
| 单局利润率 | +50-100% | +5-15%（赢时）/ -20-30%（输时） |
| 盈亏平衡点 | 几乎不存在 | 50%胜率时接近盈亏平衡 |
| 赚到1亿所需局数 | ~4局（传奇） | 200-500局 |
| 玩家决策难度 | 无脑出价 | 需要权衡风险与收益 |

**核心原则：** 玩得好的玩家应该能赚钱，但需要技巧和耐心，而不是每局躺赢。
